# MNIST From Scratch (NumPy)

A "hardcoded" implementation of a Neural Network to classify handwritten digits using only NumPy. This project focuses on understanding the underlying calculus of backpropagation without high-level libraries.

## 🚀 Features
* **Zero Dependencies:** Built using only NumPy and Math.
* **Custom Backprop:** Manual implementation of Gradient Descent and ReLU derivatives.
* **Vectorized Math:** Efficient matrix operations for forward and backward passes.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Library:** NumPy (Linear Algebra)

## 📈 Methodology
1. **Data Parsing:** Reading IDX binary files into NumPy arrays.
2. **Normalization:** Scaling pixel values to [0, 1].
3. **Architecture:** Single-layer Dense network with ReLU activation.
4. **Optimization:** Stochastic Gradient Descent (SGD).
